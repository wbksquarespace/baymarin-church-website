# BayMarin Church Website

Official source repository for the BayMarin Church website.

Firebase Hosting project: `bay-marin-church-website`
Live URL: https://bay-marin-church-website.web.app

The approved V36 website files must be added under `public/` (including `public/assets/`). Changes pushed to `main` will be deployed once the Firebase GitHub Actions service account secret is configured.
